# Backpack
Backpack is a VM Create by me,
it's 560 Line on 3.6.1 version,
the works of this VM is read from terminal get 0 and 1 ASCII Characters and convert to "BitVec<u8, Msb0>"
with 17 opcode on 3.6.1 version

# Backpack
Backpack is a runtime that read file or get input from terminal ('0', '1') and create tokens and read the tokens and do the process
started on 25 Aug 2026
## Info
opcodes information are in bc.txt File
## Source Code

File TokenCreate.rs:
This File Create Tokens From Bits Input
Example:
(000011)
This, Lexer Tokenizing This To (00001 is the opcode number of push to stack, make push token: (push(1))
00001 Is Code of Push, 1 Bit is Defualt Length of Operands
With That Rules i say it, after 00001, cut it 1 bit, that is 1
Tokens are created (push(1))
For Change or Config The Length, You can use the SetLen (10010 Opcode number)
Format of SetLen is: 10010 + 5 Bit Operand

For Delete Last Bit Of Stack
you need to use Pop (00010 Number of Opcode)
Format of Pop: Without Argmuemt, Only Opcode)

For add you can use the Plus (00100)
